Quick start

Install the compiler, create a project and start the dev server. You need nothing else — no Node, no bundler.

bash

$ curl -sSL https://raw.githubusercontent.com/monzeromer-lab/WebFluent/master/install.sh | bash $ wf init hello -t static $ cd hello $ wf serve

Open http://localhost:3000, edit src/pages/Home.wf, and save: the page reloads with your change. On Windows, install with PowerShell and type webfluent instead of wf — Getting started explains why, and covers every other way to install.

How these docs work

  • Every example is tested. Each wf code block in the guide is parsed, type-checked and built by the compiler's test suite on every release, and each whole page is run against a browser DOM. If you copy an example, it compiles.
  • The reference is generated. The components, the configuration defaults, the design tokens and the diagnostics are read from the compiler itself, so they cannot fall behind it.
  • This is version 6.0. wf --version prints the version you have; Upgrading lists what changed in each release.
  • Found a mistake? Every chapter has an Edit this page link to its source in the repository.
