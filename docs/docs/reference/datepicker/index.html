DatePicker

Form

Date input.

DatePicker(bind: …, label: …, min: …)

Example

state start: Date? = null DatePicker(bind: start, label: "Start date", min: "2026-01-01")

Renders with the class wf-datepicker, stable across releases, so a stylesheet may target it.

Props of DatePicker
Prop Type Meaning
bind: State

State variable the control reads and writes (two-way)
label: String

Visible label; also the control's accessible name
min: String

Earliest date, YYYY-MM-DD
max: String

Latest date, YYYY-MM-DD
disabled: Bool

Whether the control is inert
