 "3 minutes ago", "in 2 days" anywhere

 A translation, with placeholders and plurals

 Switches the locale, and the direction with it actions, handlers, effects

"light", "dark" or "system", kept across visits

 actions, handlers

 Shows a change now, takes it back if the action throws

 Plays an animation on a handle
