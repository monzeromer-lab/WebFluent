    • PDF Generation

    Generate PDF documents directly from .wf source files. No external dependencies — raw PDF 1.7 output.

    Enable PDF Output

    Set the output type to pdf in your project config.

    { "build": { "output_type": "pdf", "pdf": { "page_size": "A4", "margins": { "top": 72, "bottom": 72, "left": 72, "right": 72 }, "default_font": "Helvetica", "default_font_size": 12, "output_filename": "report.pdf" } } }

    Quick Start

    wf init my-report --template pdf cd my-report wf build

    This creates a sample PDF project and builds it to build/my-report.pdf.

    Document Structure

    PDF documents use the same .wf syntax. Wrap content in a Document element with optional Header and Footer.

    Page Report (path: "/", title: "Q1 Report") { Document(page_size: "A4") { Header { Text("Company Inc.", muted, small, right) } Footer { Text("Confidential", muted, small, center) } Section { Heading("Quarterly Report", h1) Text("Revenue grew 15% this quarter.") Table { Thead { Trow { Tcell("Region") Tcell("Revenue") } } Tbody { Trow { Tcell("North America") Tcell("$2.4M") } } } PageBreak() Heading("Key Highlights", h2) List { Text("Launched 3 new products") Text("Expanded to 5 new markets") } } } }

    Supported Components

    These components render in PDF output:

    Component PDF Behavior
    Document Root element. Sets page size via page_size arg.
    Header / Footer Repeated on every page. Positioned in margins.
    Section Groups content with spacing.
    Paragraph Block of text with paragraph spacing.
    PageBreak Forces a new page.
    Heading(text, h1..h6) Bold heading. h1=28pt, h2=22pt, h3=18pt...
    Text(text) Body text with word wrapping.
    Table / Thead / Tbody / Trow / Tcell Gridded table with borders and header styling.
    List Bulleted list. Add ordered modifier for numbered.
    Code(text, block) Monospace code with gray background.
    Blockquote Indented text with left bar.
    Divider Horizontal line.
    Alert(text, variant) Colored box with left accent bar.
    Badge / Tag Colored pill with white text.
    Progress(value, max) Horizontal bar.
    Card Bordered box around children.
    Image(src) Placeholder rectangle (JPEG planned).
    Spacer Vertical space. Modifiers: sm, md, lg, xl.

    Rejected Components

    Interactive and web-only components cause compile-time errors in PDF mode:

    error[pdf]: 'Button' cannot be used in PDF output (Page Report) — interactive elements are not supported in PDF error[pdf]: 'Input' cannot be used in PDF output (Page Report) — interactive elements are not supported in PDF

    Rejected: Button, Input, Select, Checkbox, Switch, Slider, Form, Modal, Dialog, Toast, Router, Navbar, Sidebar, Tabs, Video, Carousel, and all event handlers.

    Fonts

    PDF output uses the 14 standard PDF base fonts. No embedding needed.

    Font Family Variants
    Helvetica Regular, Bold, Oblique, BoldOblique
    Times Roman, Bold, Italic, BoldItalic
    Courier Regular, Bold, Oblique, BoldOblique

    Set the default font in config or override per-element with style blocks:

    Heading("Title", h1) { style { font-family: "Helvetica-Bold" color: "#1a1a2e" } }

    Styling in PDF

    Style blocks support these properties in PDF output:

    Property Values Example
    font-size Number (points) font-size: 14
    font-family Base14 font name font-family: "Courier"
    color Hex color color: "#333333"
    text-align left, center, right text-align: "center"

    Modifiers also work: bold, muted, primary, danger, success, warning, info, small, large, center, right.

    Auto Page Breaks

    Content automatically flows to a new page when it reaches the bottom margin. Headers and footers are rendered on every page, including auto-generated ones.
