# T16 — A method a number, a string or a list does not have

> In the browser the call is `x.method is not a function`, the first time the line runs. The message suggests the nearest method there is.

The page: https://webfluent.monzeromer.dev/errors/T16

```wf expect=T16
page P(path: "/", title: "T", description: "D") {
    state names = ["Ada", "Grace"]
    Heading("People").h1
    Text(names.joined(", "))
}
```

```text
error[T16]: a `[String]` has no method `joined`
 --> src/App.wf:4:16
  |
4 |     Text(names.joined(", "))
  |                ^^^^^^
  = help: Did you mean `join`?
  = docs: https://webfluent.monzeromer.dev/errors/T16
```

```wf fixed
page P(path: "/", title: "T", description: "D") {
    state names = ["Ada", "Grace"]
    Heading("People").h1
    Text(names.join(", "))
}
```

**Fix:** The method the message suggests — here `join`.
