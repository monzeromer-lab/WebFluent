# E101 — A component nothing declares

> An element, a `layout:` or a part names a component that no `component` declares and no built-in has. Often a misspelling.

The page: https://webfluent.monzeromer.dev/errors/E101

```wf expect=E101
page P(path: "/", title: "T", description: "D") {
    Heading("Save").h1
    Buton("Save")
}
```

```text
error[E101]: unknown component `Buton`: no `component Buton` is declared
 --> src/App.wf:3:5
  |
3 |     Buton("Save")
  |     ^^^^^
  = help: did you mean `Button`? Or declare `component Buton { … }`
  = docs: https://webfluent.monzeromer.dev/errors/E101
```

```wf fixed
page P(path: "/", title: "T", description: "D") {
    Heading("Save").h1
    Button("Save")
}
```

**Fix:** Check the spelling, or declare it with `component Buton { … }`.
