# T07 — A condition that is always true

> A list, a record or an action used as a condition: it is never `false`, so the branch always runs.

The page: https://webfluent.monzeromer.dev/errors/T07

```wf expect=T07
page P(path: "/", title: "T", description: "D") {
    state items = ["a"]
    Heading("List").h1
    if items { Text("There are items") }
}
```

```text
error[T07]: `if` reads `items` as a condition, but a list is always true
 --> src/App.wf:4:5
  |
4 |     if items { Text("There are items") }
  |     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  = help: Ask about its length: `items.length > 0`
  = docs: https://webfluent.monzeromer.dev/errors/T07
```

```wf fixed
page P(path: "/", title: "T", description: "D") {
    state items = ["a"]
    Heading("List").h1
    if items.length > 0 { Text("There are items") }
}
```

**Fix:** Ask the question you mean: `items.length > 0`, `user != null`.
