# E109 — An element this output cannot draw

> A PDF or a slide deck has no buttons, inputs, handlers or routes; an interactive element in one would be drawn as nothing.

The page: https://webfluent.monzeromer.dev/errors/E109

A `Button`, an `Input`, a handler or a `Router` in a project whose
`output_type` is `pdf` or `slides`. Paper has no controls (`Button`,
`Input`, `Select`, `Checkbox`, `Radio`, `Switch`, `Slider`, `DatePicker`,
`FileUpload`, `Textarea`, `Form`, `IconButton`, `ButtonGroup`, `Dropdown`), no navigation
(`Router`, `Navbar`, `Sidebar`, `Tabs`, `Menu`), no overlays (`Modal`,
`Dialog`, `Popover`, `Toast`, `Tooltip`), no media that plays (`Video`,
`Audio`, `Carousel`), no other page inside it (`Frame`) and nothing a
script draws (`Host`, `Element`, `Portal`). **Fix:** draw it as text, or build the
page as a site.
