# X05 — `use` of a store nothing declares

> `use` names a store the page depends on; one that is not declared is a misspelling, and every read of it is nothing.

The page: https://webfluent.monzeromer.dev/errors/X05

```wf expect=X05
store Cart { state items = [] }
page P(path: "/", title: "T", description: "D") {
    use Carts
    Heading("Cart").h1
}
```

```text
error[X05]: `use Carts` names a store nothing declares
 --> src/App.wf:3:5
  |
3 |     use Carts
  |     ^^^
  = help: The stores are `Cart`
  = docs: https://webfluent.monzeromer.dev/errors/X05
```

```wf fixed
store Cart { state items = [] }
page P(path: "/", title: "T", description: "D") {
    use Cart
    Heading("Cart: {Cart.items.length}").h1
}
```

**Fix:** Name a store that exists — here `Cart`.
