# A08 — A dialog with no title

> A `Modal` or `Dialog` with no `title:`, which is its accessible name.

The page: https://webfluent.monzeromer.dev/errors/A08

```wf expect=A08
page P(path: "/", title: "T", description: "D") {
    state open = false
    Heading("Modal").h1
    Modal(visible: open) { Text("Hello") }
}
```

```text
warning[A08]: Modal missing "title" attribute
 --> src/App.wf:4:5
  |
4 |     Modal(visible: open) { Text("Hello") }
  |     ^^^^^
  = help: Add a title: Modal(visible: state, title: "Dialog Title")
  = docs: https://webfluent.monzeromer.dev/errors/A08
```

```wf fixed
page P(path: "/", title: "T", description: "D") {
    state open = false
    Heading("Modal").h1
    Modal(visible: open, title: "Hello") { Text("Hello") }
}
```

**Fix:** `Modal(visible: open, title: "Delete this?")` — the title is its accessible name.
