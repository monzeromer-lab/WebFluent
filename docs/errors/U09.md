# U09 — An unkeyed loop whose items hold state

> With no `by`, a change to the list redraws every item, and what an item holds — a field being typed in, a component's own state — starts again.

The page: https://webfluent.monzeromer.dev/errors/U09

Warning.

```wf expect=U09
page P(path: "/", title: "T", description: "D") {
    state rows = [{ id: 1, name: "a" }]
    Heading("Rows").h1
    for r in rows { Input(bind: r.name, label: "Name") }
}
```

```text
warning[U09]: this `for` has no `by`, and each item holds a `Input`, which starts again whenever the list changes
 --> src/App.wf:4:5
  |
4 |     for r in rows { Input(bind: r.name, label: "Name") }
  |     ^^^
  = help: Key it: `for r in … by r.id`
  = docs: https://webfluent.monzeromer.dev/errors/U09
```

```wf fixed
page P(path: "/", title: "T", description: "D") {
    state rows = [{ id: 1, name: "a" }]
    Heading("Rows").h1
    for r in rows by r.id { Input(bind: r.name, label: "Name") }
}
```

**Fix:** Key it: `for r in rows by r.id`.
