# C03 — A part outside the component it belongs to

> `Select.Option`, `Table.Row`, `Card.Header` — a part is placed inside its owner. Outside it, it draws a stray element with nothing around it.

The page: https://webfluent.monzeromer.dev/errors/C03

```wf expect=C03
page P(path: "/", title: "T", description: "D") {
    Heading("Plans").h1
    Select.Option("Pro", value: "pro")
}
```

```text
error[C03]: `Select.Option` is a part of `Select`, and it is not inside one
 --> src/App.wf:3:5
  |
3 |     Select.Option("Pro", value: "pro")
  |     ^^^^^^^^^^^^^
  = help: Place it in a `Select { … }`
  = docs: https://webfluent.monzeromer.dev/errors/C03
```

```wf fixed
page P(path: "/", title: "T", description: "D") {
    state plan = "pro"
    Heading("Plans").h1
    Select(bind: plan, label: "Plan") { Select.Option("Pro", value: "pro") }
}
```

**Fix:** Place the part inside its owner: `Select(bind: plan) {
Select.Option(…) }`.
