    • Animation System

    Declarative animations built into the language. No CSS keyframes to write.

    Mount Animations

    Add an animation modifier to any component. It plays when the element appears. Hover each card to replay.

    fadeIn

    Fades from transparent

    slideUp

    Slides from below

    scaleIn

    Scales from 90%

    slideDown

    Slides from above

    slideLeft

    Slides from right

    bounce

    Bouncy entrance

    shake

    Horizontal shake

    pulse

    Gentle scale pulse

    slideRight

    Slides from left

    Card(elevated, fadeIn) { ... } Heading("Title", h1, slideUp) Button("Click", primary, bounce)

    Live: Conditional Animation

    Toggle the switch to see enter/exit animations on the card below.

    if showCard, animate(scaleIn, fadeOut) { Card(elevated) { Text("Animated content") } }

    All 12 Animations

    Name Effect Usage
    fadeIn / fadeOut Opacity fade Card(elevated, fadeIn)
    slideUp / slideDown Vertical slide + fade Heading("Hi", h1, slideUp)
    slideLeft / slideRight Horizontal slide + fade Text("Hello", slideLeft)
    scaleIn / scaleOut Scale from/to 90% Badge("New", scaleIn)
    bounce Bouncy entrance Button("Go", bounce)
    shake Horizontal shake Alert("Error!", shake)
    pulse Scale pulse (infinite) Badge("Live", pulse)
    spin 360-degree rotation Spinner(spin)

    Conditional Animations

    Attach enter and exit animations to if blocks.

    if visible, animate(slideUp, fadeOut) { Card { Text("Appears with slideUp, exits with fadeOut") } } if expanded, animate(scaleIn, scaleOut) { Text("Scales in and out") }

    List Stagger

    Animate list items with staggered delays.

    for item in items, animate(slideUp, fadeOut, stagger: "50ms") { Card { Text(item.name) } }

    Transition Blocks

    Smooth CSS transitions on property changes.

    Button("Hover me") { transition { background 200ms ease transform 150ms spring } }
