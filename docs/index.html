    Why WebFluent?

    Everything you need, built into the language.

    Declarative Syntax

    No XML, no JSX. Write UI as readable declarations with curly braces and parentheses.

    50+ Components

    Navbar, Card, Modal, Form, Table, Tabs, and more. Every component has a default design.

    Signal Reactivity

    Fine-grained DOM updates without a virtual DOM. Only affected nodes update.

    Design System

    Design tokens for colors, spacing, typography. 4 themes. Switch with one config line.

    Animations

    12 built-in animations as modifiers. Enter/exit on conditionals and loops with stagger.

    i18n + RTL

    JSON translations, t() function, reactive locale switching, automatic RTL direction.

    SSG

    Pre-render pages at build time. Instant content, then JS hydrates for interactivity.

    A11y Linting

    12 compile-time checks for missing alt text, labels, headings. Never blocks the build.

    Zero Dependencies

    Compiles to vanilla HTML, CSS, JS. No runtime framework. Pure web standards output.
