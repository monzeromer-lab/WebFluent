    • Accessibility Linting

    WebFluent checks your code for accessibility issues at compile time. Warnings are printed during build but never block compilation.

    How It Works

    The linter runs automatically after parsing, before code generation. It walks the AST and checks each component against 12 rules.

    $ wf build Building my-app... Warning [A01]: Image missing "alt" attribute at src/pages/Home.wf:12:5 Add alt text: Image(src: "...", alt: "Description of image") Warning [A03]: Input missing "label" attribute at src/pages/Form.wf:8:9 Add a label: Input(text, label: "Username") 3 pages, 2 components, 1 stores Build complete with 2 accessibility warning(s).

    Lint Rules

    Rule Component Check
    A01 Image Must have alt attribute
    A02 IconButton Must have label attribute (no visible text)
    A03 Input Must have label or placeholder
    A04 Checkbox, Radio, Switch, Slider Must have label attribute
    A05 Button Must have text content
    A06 Link Must have text content or children
    A07 Heading Must not be empty
    A08 Modal, Dialog Must have title attribute
    A09 Video Must have controls attribute
    A10 Table Must have Thead header row
    A11 Heading Levels must not skip (h1 to h3)
    A12 Page Must have exactly one h1 (not for Presentation or Document)
    A13 Theme Colour pairings must clear the WCAG AA contrast ratio
    S01 Page Must have a title
    S02 Page Should have a description, or its search snippet gets written for it
    S03 Page A description over ~160 characters is truncated in results
    S04 Page Two pages must not claim one route
    V01 Any A bare word that resolves to nothing
    V02 Any A real modifier whose class no stylesheet defines

    Examples

    Bad (triggers warning)

    Image(src: "/photo.jpg") IconButton(icon: "close") Input(text) Checkbox(bind: agreed) Button()

    Good (no warnings)

    Image(src: "/photo.jpg", alt: "Team photo") IconButton(icon: "close", label: "Close") Input(text, label: "Username") Checkbox(bind: agreed, label: "I agree") Button("Save")
