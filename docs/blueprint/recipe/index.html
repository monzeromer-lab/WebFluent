How to fetch and show a list

Ask a server for a list, show a placeholder while it comes, and draw each item. Done in 14 lines.

Open in Playground
type User { id: String, name: String } page Team(path: "/team", title: "Team") { resource users: [User] = fetch("/api/users", on: .focus) match users { loading { Skeleton(height: "20px") } error(e) { Alert(e.message).danger } ready(list) { for u in list by u.id { Text(u.name) } } } }

Compiled by WebFluent 6.0 when this site was built

How it works

1

Say what comes back

type User says what each item is, so a typo in u.name is caught before it ships.

2

Ask for it

resource asks once, and again when the reader comes back to the tab (on: .focus).

Variations

resource users = Backend.users(page: n, paginate: .page)
