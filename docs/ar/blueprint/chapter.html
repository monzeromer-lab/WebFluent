page Home(path: "/", title: "Hello") { state count = 0 Heading("Hello, WebFluent").h1 Text("Clicked {count} times") Button("+1").primary { on click { count = count + 1 } } }

ما الذي يُعاد رسمه

لا شيء يعيد تشغيل الصفحة كلها. يرى المترجم أن Text يقرأ count، فيربط عقدة النص تلك به.

قادم من React؟

useState هو state، ولا دالة للتعيين: أسند إليه مباشرة.

Warning

A state that reads now and is never assigned holds the moment the page opened.

تحقق من فهمك

Check your understanding

A page has state n = 0 and derived d = n * 2, and shows Text("{d}"). You set n = 5. What redraws?

What you learned

  • state holds a value that changes.

  • Only what reads a value draws again.

  • derived is worked out from other values.
