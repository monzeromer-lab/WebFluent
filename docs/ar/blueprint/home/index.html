HTML & CSS

التثبيت

ملف تنفيذي واحد، بلا Node. السطر الأول يثبّته على Linux وmacOS، والسطران التاليان يصنعان موقعًا ويشغّلانه.

bash

curl -sSL https://raw.githubusercontent.com/monzeromer-lab/WebFluent/master/install.sh | bash wf init my-site -t static cd my-site && wf serve
