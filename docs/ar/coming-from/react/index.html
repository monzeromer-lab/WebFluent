قادم من

WebFluent لمطوّري React

معظم ما تعرفه من React ينتقل معك: مكوّنات لها خصائص (props)، وحالة، وموجّه مسارات (router)، ومتاجر مشتركة. الفرق الذي عليك أن تتذكّره أن WebFluent مترجم (compiler) بترميز ذي أنواع، وليس مكتبة: جسم المكوّن يعمل مرة واحدة، ولا يتحدّث إلا النص أو السمة أو النمط الذي يقرأ قيمة تغيّرت. لا خطافات (hooks)، ولا مصفوفات اعتماديات، ولا دوال ضبط (setters).
