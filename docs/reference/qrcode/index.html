QrCode

A QR code for a URL or any text, drawn as vector graphics when the page is built.

QrCode(_ value: String, color: String, background: String)

Since 5.2.0

Props

Props of QrCode
Prop Type Meaning
value String (positional)

What it encodes
color: String

The colour of the dark modules
background: String

The colour behind them

Attribute families: global, aria, data. Plus the universal props on every element: animate:, exit:, speed:, class:, ref:.

Flags and cases

A flag is written after the parentheses with a dot: a Bool prop, or a case of one of the element's enum props. A case the enum lacks is an error with a hint.

.dropInside

.trapFocus

Events

Every element also takes the props, the events and the attribute families listed on every element.

Slots and parts

Slots

It takes no slots.

Parts

It has no parts.

Example

wf

QrCode("https://example.com/report/q1")

Renders with the class wf-qr, stable across releases, so a stylesheet may target it.

Codes this can raise

E103

A flag, case, part, event or slot the component does not have

C04

An attribute a built-in does not declare

The Stage's controls are drawn from the props' kinds: a choice for each enum, a switch for each Bool, a field for each String. They change the preview once the compiler runs in your browser.
