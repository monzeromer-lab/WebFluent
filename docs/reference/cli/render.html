wf render

Render a .wf template with JSON data

wf render TEMPLATE [options]

Writes: the file --output names.

Options

Options of wf render
Option Type Meaning
TEMPLATE path

Template file (.wf or .wfx), or a directory: every template under it as one, components shared
--data DATA path

JSON data file (reads stdin if omitted)
--format, -f FORMAT html | html-fragment | pdf | slides

Output format: "html" (default), "html-fragment", "pdf", or "slides"
--output, -o OUTPUT path

Output file (stdout if omitted)
--theme THEME text

Which Theme declared in the template to render with. Only needed when the template declares more than one
--token NAME=VALUE text, repeats

A design token over the theme's, NAME=VALUE; may be given more than once
--page PAGE text

The page to render, by name, when the template has several
--lang LANG text

The document's language, <html lang> (default: the page's lang:, else en)
