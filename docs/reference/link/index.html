Link

Client-side navigation link; its label or its block is the link text.

Link(_ label: String, to: Path, active: Enum) { … }

Before 5.0

active

prefix

Prop Type Meaning

 String (positional)

The link text

 Path

Route to navigate to; the link whose to matches the current route carries .active and aria-current="page"

 .prefix

How the link decides it is the current one

Attribute families: global, aria, data, anchor. Plus the 21 universal props every element takes: animate:, exit:, speed:, duration:, delay:, easing:, stagger:, on:, count:, shared:, class:, ref:, drag:, dragGroup:, dropValue:, dropAxis:, dropInside:, trapFocus:, mount:, update:, cleanup:.

Flags and cases

A flag is written after the parentheses with a dot: a Bool prop, or a case of one of the element's enum props. A case the enum lacks is an error with a hint.

.prefix

Events

The DOM events it is drawn to answer. Any other DOM event works too, in an on … { } handler.

DOM events Link answers
Event Sends Meaning
on click DOM The element was clicked or activated

Every element also takes the props, the events and the attribute families listed on every element.

Example

wf

Link("About us", to: "/about") Link("Guide", to: "/docs", active: .prefix) Link(to: "https://example.com", target: "_blank") { Text("Example") }

Renders with the class wf-link, stable across releases, so a stylesheet may target it.

Codes this can raise

E103

A flag, case, part, event or slot the component does not have

E107

A URL a browser would run

C04

An attribute a built-in does not declare

R01

A route to nothing

A06

A link with no text

The Stage's controls are drawn from the props' kinds: a choice for each enum, a switch for each Bool, a field for each String. They change the preview once the compiler runs in your browser.
