Image

Image; alt is required for accessibility (rule A01). Given an image the program declares, it becomes a <picture> with every width the build wrote.

Image(_ source: Any, src: String, sizes: String, placeholder: Enum, …)

Before 5.0

placeholder

blur

color

none

loading

lazy

eager

shape

rounded

circle

Drawn here once the compiler runs in your browser. Until then, the example below shows how it is written.

Props

Props of Image
Prop Type Meaning
source Any (positional)

An image the program declares, or a URL
src: String

Image URL
sizes: String

How wide it will be shown, so the browser picks a width: (max-width: 768px) 100vw, 1200px
placeholder: .blur .color .none

What fills the box while the image loads
alt: String

Text alternative; empty for a purely decorative image
width: Number

Intrinsic width
height: Number

Intrinsic height
loading: .lazy .eager

Unset, the first image on a page is eager at high priority and the rest lazy
shape: .rounded .circle

Shape

Attribute families: global, aria, data. Plus the universal props on every element: animate:, exit:, speed:, class:, ref:.

Flags and cases

A flag is written after the parentheses with a dot: a Bool prop, or a case of one of the element's enum props. A case the enum lacks is an error with a hint.

.blur

.color

.none

.lazy

.rounded

.dropInside

.trapFocus

Events

Every element also takes the props, the events and the attribute families listed on every element.

Slots

Example

wf

Image(src: "/team.jpg", alt: "The team at the launch", width: 1200, height: 630) Image(src: "/flourish.svg", alt: "")

Renders with the class wf-image, stable across releases, so a stylesheet may target it.

Codes this can raise

E103

A flag, case, part, event or slot the component does not have

C04

An attribute a built-in does not declare

R04

A relative URL on a nested route

D01

A file the project does not have

A01

An image with no alt text

The Stage's controls are drawn from the props' kinds: a choice for each enum, a switch for each Bool, a field for each String. They change the preview once the compiler runs in your browser.
