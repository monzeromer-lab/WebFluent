### Navigation

| Component | Usage |
|-----------|-------|
| `Navbar` | `Navbar { Navbar.Brand { ... } Navbar.Links { ... } Navbar.Actions { ... } }` |
| `Sidebar` | `Sidebar { Sidebar.Header { ... } Sidebar.Item(to: "/", icon: "home") { ... } Sidebar.Divider }` |
| `Link` | `Link(to: "/path") { Text("Label") }` — the link whose `to` matches the current route carries `.active` and `aria-current="page"`; `active: .prefix` also matches routes beneath it; a `to` with a query (`"/?show=open"`) matches only when the address has those values too, and a plain link to the same path then gives way to it |
| `Tabs` | `Tabs(bind: tab, label: "Account") { Tabs.Page("Profile", value: "profile") { ... } Tabs.Page("Billing", value: "billing", disabled: !isOwner) { ... } }` — `bind:` reads and writes the open page's `value:` (its place from 0 without one); `value:` only reads it, and `on change(v)` hears the one picked; `.vertical`; `.manual` opens a tab on Enter or Space rather than as the focus reaches it. Only the open tab is in the Tab order; the arrow keys move (the other way round in a right-to-left page), Home and End go to the ends, a disabled tab is passed over |
| `Breadcrumb` | `Breadcrumb { Breadcrumb.Item(to: "/") { Text("Home") } Breadcrumb.Item { Text("Current") } }` |
| `CommandPalette` | `CommandPalette(open: palette) { CommandPalette.Group("Pages") { CommandPalette.Item("Home", icon: "home", shortcut: "mod+h") { on select { navigate("/") } } } }` — a modal of a field and the items it filters by their words (a group left empty goes); the arrows go through what is left, Enter or a press runs it (`on select`) and closes; emptied each time it closes |
| `Pagination` | `Pagination(bind: page, pages: total, siblings: 1)` — Previous, the first and last pages, those around the current one, `…` for the rest, Next; the current is `aria-current="page"`; pages count from 1 |
| `Stepper` | `Stepper(bind: step) { Stepper.Step("Account") { … }  Stepper.Step("Billing", done: billed) { … } }` — the steps listed with their state (current, done, an `error:`), the current one's block shown; steps count from 0; `.linear` keeps a step ahead out of reach |
| `OnThisPage` | `OnThisPage(levels: 2, label: "On this page")` — the page's headings (`h2`, and `h3` with `levels: 2`) as links, an id given to one that has none, the one being read marked `aria-current="location"`; listed in the static paint too, each heading given the `id` the live page would give it |
| `Menu` | `Menu(trigger: "Options") { Menu.Item(shortcut: "F2") { ... } Menu.Divider Menu.Sub(label: "Move to") { ... } }`, or opened by state: `Menu(visible: asked, at: point)` (a context menu, `point = { x: e.clientX, y: e.clientY }`) or `anchor: someRef`; `placement:`, `on close(reason)`. Items take `shortcut:`, `checked:`, `disabled:`. Drawn in the top layer |
| `NavigationMenu` | `NavigationMenu(label: "Main") { NavigationMenu.Item("Products") { Link("Editor", to: "/editor") … }  NavigationMenu.Link("Pricing", to: "/pricing") }` — a site's navigation whose entries open panels (a mega menu) as disclosures: one open at a time, the arrow keys along the row (the other way round right to left), Down into a panel at its first link, Escape, a press outside or the focus leaving closes it |
| `Menubar` | `Menubar(label: "Editor") { Menubar.Menu("File") { Menu.Item(shortcut: "mod+n") { … } }  Menubar.Menu("Edit") { … } }` — File, Edit and View as in a desktop app: one Tab stop, the arrow keys along it; Down or Enter opens a menu at its first item, and with one open Left and Right (and the pointer) open the one beside it; its menus take what a `Menu` takes, and an item's `shortcut:` runs it from anywhere on the page |
| `ContextMenu` | `ContextMenu { FileRow(f)  ContextMenu.Items(label: "File actions") { Menu.Item { … } } }` — what it wraps, and a menu that a right-click, a long press, the menu key or Shift+F10 inside it opens where it happened (at the focused element for a key), the focus on its first item |
| `BottomNavigation` | `BottomNavigation(label: "Sections") { BottomNavigation.Item("Home", to: "/", icon: "home") … }` — a phone's tab bar along the bottom of the screen: each entry its icon over its words, at least 44px to press, clear of the home indicator (`env(safe-area-inset-bottom)`), the current route's marked `aria-current="page"`; the page keeps room for it |
| `PrevNext` | `PrevNext { PrevNext.Prev("Forms", to: "/forms")  PrevNext.Next("Stores", to: "/stores") }` — the pages before and after this one, each a link (`rel="prev"`/`"next"`) saying which way (`label:` to say it otherwise) above the page's title; one alone keeps its side |
