# E108 — An `env` name that is not public

> Whatever a page reads from `env` is in the bundle, where anyone can read it. A name a page reads must begin `PUBLIC_` or be listed in `public_env`.

The page: https://webfluent.monzeromer.dev/errors/E108

A page that reads `env.STRIPE_SECRET` draws ``env.STRIPE_SECRET is not
public, and a page reads what is in the bundle`` (the example is not
compiled here: what it draws depends on the config's `public_env`):

```wf no-check
page P(path: "/", title: "T", description: "D") {
    Heading(env.STRIPE_SECRET).h1
}
```

**Fix:** rename it `PUBLIC_…` (`env.PUBLIC_APP_NAME`) or list it in
`public_env` — only if anyone may read it. A value the page must not read
belongs behind a request ([Environments and
secrets](https://webfluent.monzeromer.dev/recipes/environments-and-secrets.md)).
