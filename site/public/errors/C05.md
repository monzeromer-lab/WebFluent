# C05 — A positional argument a built-in does not take

> The built-in takes its arguments by name; one written without a name is not given to anything.

The page: https://webfluent.monzeromer.dev/errors/C05

Warning.

```wf expect=C05
page P(path: "/", title: "T", description: "D") {
    Heading("Rule").h1
    Divider("thin")
}
```

```text
warning[C05]: Divider takes no positional argument
 --> src/App.wf:3:13
  |
3 |     Divider("thin")
  |             ^
  = help: Name it: the registry lists the props it takes
  = docs: https://webfluent.monzeromer.dev/errors/C05
```

```wf fixed
page P(path: "/", title: "T", description: "D") {
    Heading("Rule").h1
    Divider()
}
```

**Fix:** Name it, with one of the props the built-in takes.
