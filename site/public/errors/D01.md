# D01 — A file the project does not have

> A site-relative `src:`, `poster:`, `captions:` or `transcript:` names a file that is not in `public/`; the page asks for it and gets nothing.

The page: https://webfluent.monzeromer.dev/errors/D01

Warning. `Image(src: "/img/hero.png")` when `public/img/hero.png` does not
exist (also a `Video`'s `poster:` and `captions:`, an `Audio`'s
`transcript:`, and a worker's `spawn("/workers/css.js")`): the page asks for it and gets a 404. **Fix:** put the file in `public/`, or correct the path.
