# V05 — A CSS property no browser knows

> A misspelled property — `colr:` — is ignored by the browser; nothing tells you why the style did not take.

The page: https://webfluent.monzeromer.dev/errors/V05

Warning.

```wf expect=V05
page P(path: "/", title: "T", description: "D") {
    Heading("Hello") {
        style { colr: red }
    }
}
```

```text
warning[V05]: `colr` is not a CSS property, so the browser ignores it
 --> src/App.wf:3:17
  |
3 |         style { colr: red }
  |                 ^^^^
  = help: Did you mean `color`?
  = docs: https://webfluent.monzeromer.dev/errors/V05
```

```wf fixed
page P(path: "/", title: "T", description: "D") {
    Heading("Hello").h1 {
        style { color: red }
    }
}
```

**Fix:** The property the message suggests — here `color`. A custom
property is written `--name`.
