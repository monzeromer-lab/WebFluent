# E003 — Indentation that lines up with no block

> In a `.wfx` file a line opens a block by being followed by a deeper one, and closes blocks by coming back out. A line that comes back to an…

The page: https://webfluent.monzeromer.dev/errors/E003

In a `.wfx` file, a line that comes back out to an indentation no enclosing
block has. Saved as `src/App.wfx`, this draws `E003` (the example is not
compiled here, where every example is read as a `.wf` file):

```wfx no-check
page Home(path: "/")
    Row
        Text("a")
      Text("b")
```

**Fix:** Line the line up with the block it belongs to.
