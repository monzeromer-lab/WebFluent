# X04 — A derived value that changes something

> A `derived` value is worked out whenever what it reads changes, as often as the page needs it; one that calls an action that assigns changes state…

The page: https://webfluent.monzeromer.dev/errors/X04

```wf expect=X04
page P(path: "/", title: "T", description: "D") {
    state count = 0
    action next() {
        count = count + 1
        return count
    }
    derived ticket = next()
    Heading("Ticket {ticket}").h1
}
```

```text
error[X04]: `ticket` is worked out by calling `next(…)`, which assigns `count`
 --> src/App.wf:7:5
  |
7 |     derived ticket = next()
  |     ^^^^^^^^^^^^^^^^^^^^^^^
  = help: A derived value only reads; call the action from a handler, and derive from what it sets
  = docs: https://webfluent.monzeromer.dev/errors/X04
```

```wf fixed
page P(path: "/", title: "T", description: "D") {
    state count = 0
    action next() {
        count = count + 1
        return count
    }
    derived ticket = count
    Heading("Ticket {ticket}").h1
    Button("Next") { on click { next() } }
}
```

**Fix:** Call the action from a handler; derive from the state it sets.
