# N04 — A result nothing reads

The page: https://webfluent.monzeromer.dev/errors/N04

Warning.

```wf expect=N04
type Todo { id: String, title: String }

api Backend(base: "/api") {
    post create(title: String) at "todos" -> Todo!
}

store Todos {
    action add(title: String) {
        await Backend.create(title: title)
    }
}

page P(path: "/", title: "T", description: "D") {
    use Todos
    Heading("Todos").h1
    Button("Add milk") { on click { Todos.add("Milk") } }
}
```

```text
warning[N04]: what `await Backend.create(…)` answers is not read: whether it worked goes nowhere
 --> src/App.wf:9:9
  |
9 |         await Backend.create(title: title)
  |         ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  = help: Match it — `match await … { .ok(v) { … } .err(e) { … } }` — or pass a failure up with `try await …`
  = docs: https://webfluent.monzeromer.dev/errors/N04
```

```wf fixed
type Todo { id: String, title: String }

api Backend(base: "/api") {
    post create(title: String) at "todos" -> Todo!
}

store Todos {
    state failed = ""
    action add(title: String) {
        match await Backend.create(title: title) {
            .ok(_) { failed = "" }
            .err(e) { failed = e.message }
        }
    }
}

page P(path: "/", title: "T", description: "D") {
    use Todos
    Heading("Todos").h1
    Button("Add milk") { on click { Todos.add("Milk") } }
    Text(Todos.failed)
}
```

A call of an endpoint never throws: it returns a result, `.ok(value)` or
`.err(error)`. Awaited on its own, the result is dropped, and with it
whether the call worked. If the server refused the todo, or the network was
gone, nothing on the page says so.

**Fix:** `match` the result and say what happened in each case, or write
`try await …` in an action that declares an error, to pass a failure up to
whatever called it.
