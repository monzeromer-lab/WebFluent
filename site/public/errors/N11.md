# N11 — `Any` or `Map` where a service meets the program

> What crosses to a service has a type the program names: a record, a dictionary, or `Json` — never `Any` or `Map`.

The page: https://webfluent.monzeromer.dev/errors/N11

Error.

```wf expect=N11
api Backend(base: "/api") {
    post signUp(body: Map) at "users" -> !
}

page P(path: "/", title: "T", description: "D") {
    Heading("Join").h1
    Button("Join") { on click { Backend.signUp(body: { email: "ada@example.com" }) } }
}
```

```text
error[N11]: `body` of `Backend.signUp` is `Map`, which says nothing of what it holds
 --> src/App.wf:2:5
  |
2 |     post signUp(body: Map) at "users" -> !
  |     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  = help: Name it: a `type` with its fields, a dictionary `[String: T]`, or `Json` for JSON whose shape is open
  = docs: https://webfluent.monzeromer.dev/errors/N11
```

```wf fixed
type SignUp { email: String }

api Backend(base: "/api") {
    post signUp(body: SignUp) at "users" -> !
}

page P(path: "/", title: "T", description: "D") {
    Heading("Join").h1
    Button("Join") { on click { Backend.signUp(body: SignUp(email: "ada@example.com")) } }
}
```

A request is where a program meets data it did not make. What crosses —
an endpoint's parameters and body, its answer, what a `resource` holds,
what an `http` call answers — is a type the program names, so the checker
can hold every use of it to its fields and every answer can be checked
when it arrives. `Any` and `Map` say nothing of what is in them.

`http.get` names what it answers where the answer goes: `let rows: [Row] =
try await http.get(url)`, or `resource rows: [Row] = http.get(url)`. A
write whose answer nothing reads needs no type for it.

**Fix:** Name the type: a `type` with the fields the service sends, a
dictionary `[String: T]` for one keyed by name, or `Json` for JSON whose
shape really is open, which is then matched or decoded. The quick fix
writes `Json`.
