# A16 — One id on several elements

> A literal `id:` inside a `for`, or in a component placed more than once, gives several elements one id; a label's `for` and `aria-*` find only the first.

The page: https://webfluent.monzeromer.dev/errors/A16

Warning.

```wf expect=A16
page P(path: "/", title: "T", description: "D") {
    state rows = ["a", "b"]
    Heading("Rows").h1
    for r in rows by r { Text(r, id: "row") }
}
```


```wf fixed
page P(path: "/", title: "T", description: "D") {
    state rows = ["a", "b"]
    Heading("Rows").h1
    for r in rows by r { Text(r, id: "row-{r}") }
}
```

**Fix:** Make it unique — `id: "row-{r}"` — or drop it.
