# T15 — A `match` that misses a case, or has one twice

> A `match` with no `else` must give every case of the enum an arm — a value with a case it misses would match nothing. A case with two arms reaches…

The page: https://webfluent.monzeromer.dev/errors/T15

```wf expect=T15
enum Status { draft, review, live }
page P(path: "/", title: "T", description: "D") {
    state status: Status = .draft
    Heading("Status").h1
    match status {
        .draft { Text("Draft") }
        .live { Text("Live") }
    }
}
```

```text
error[T15]: this `match` on `status` has no arm for `.review`, and no `else`
 --> src/App.wf:5:5
  |
5 |     match status {
  |     ^^^^^
  = help: Add an arm for each, or `else { … }` for the rest
  = docs: https://webfluent.monzeromer.dev/errors/T15
```

```wf fixed
enum Status { draft, review, live }
page P(path: "/", title: "T", description: "D") {
    state status: Status = .draft
    Heading("Status").h1
    match status {
        .draft { Text("Draft") }
        .review { Text("In review") }
        .live { Text("Live") }
    }
}
```

**Fix:** Give every case its arm, or add `else { … }` for the rest. A
`match` expression that covers every case needs no `else`:
`derived label = match status { .draft { "Draft" } .review { "In review" } .live { "Live" } }`.
