# E103 — A flag, case, part, event or slot the component does not have

> What a component takes comes from one registry for the built-ins and from the declaration for your own; a word that resolves to nothing there does…

The page: https://webfluent.monzeromer.dev/errors/E103

```wf expect=E103
page P(path: "/", title: "T", description: "D") {
    Heading("Save").h1
    Button("Save").huge
}
```

```text
error[E103]: Button has no flag or enum case `huge`
 --> src/App.wf:3:19
  |
3 |     Button("Save").huge
  |                   ^^^^^
  = help: Its tones are .primary, .secondary, .success, .danger, .warning, .info; its sizes are .sm, .md, .lg; its shapes are .rounded, .pill; its widths are .full; its types are .button, .submit, .reset; it also takes .disabled, .loading, .outlined; and the animation flags every element takes
  = docs: https://webfluent.monzeromer.dev/errors/E103
```

```wf fixed
page P(path: "/", title: "T", description: "D") {
    Heading("Save").h1
    Button("Save").lg
}
```

**Fix:** Use one the message lists — it names the component's own flags
and cases, each enum prop's under its name, and every event or slot it
takes; the animation and speed flags every element takes (`.fadeIn`,
`.fast`) are named once rather than listed.
