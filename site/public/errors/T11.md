# T11 — A `match` on something that cannot be matched

> A `match` is over a read, a result, a connection or an enum; its arms are the cases of that kind.

The page: https://webfluent.monzeromer.dev/errors/T11

```wf expect=T11
page P(path: "/", title: "T", description: "D") {
    state n = 1
    Heading("Match").h1
    match n {
        .loading { Spinner }
        else { Text("?") }
    }
}
```

```text
error[T11]: `match` needs a resource or an enum, but `n` is `Number`
 --> src/App.wf:4:5
  |
4 |     match n {
  |     ^^^^^^^^^
  = help: Use `if` for a condition; `match` chooses among a resource's states or an enum's cases
  = docs: https://webfluent.monzeromer.dev/errors/T11
```

```wf fixed
page P(path: "/", title: "T", description: "D") {
    state n = 1
    Heading("Match").h1
    if n == 1 { Text("One") } else { Text("?") }
}
```

**Fix:** Use `if` for a condition; `match` takes a read (a `resource`), a result (`.ok`, `.err`), a connection or an enum.
