# wf theme

> The theme the build uses: every token, declared or inherited, where each is used, and its contrast pairs

```bash
wf theme [options]
```

## Options

| Option | Meaning |
|---|---|
| `--dir, -d DIR` | Project directory (default: current directory) |
| `--json` | Print JSON, for tools |
