# T25 — A state whose first value does not say what it holds

Error.

```wf expect=T25
type Todo { id: String, title: String }

page P(path: "/", title: "Todos", description: "D") {
    state items = []
    Heading("Todos").h1
    Button("Add") { on click { items = items.concat([Todo(id: "1", title: "Milk")]) } }
    for todo in items by todo.id { Text(todo.title) }
}
```

```text
error[T25]: `state items`'s first value does not say what it holds
 --> src/App.wf:4:5
  |
4 |     state items = []
  |     ^^^^^^^^^^^^^^^^
  = help: Write what it holds: `state items: [Todo] = …`
  = docs: https://webfluent.monzeromer.dev/errors/T25
```

```wf fixed
type Todo { id: String, title: String }

page P(path: "/", title: "Todos", description: "D") {
    state items: [Todo] = []
    Heading("Todos").h1
    Button("Add") { on click { items = items.concat([Todo(id: "1", title: "Milk")]) } }
    for todo in items by todo.id { Text(todo.title) }
}
```

What another declaration, another file or a caller sees is declared; what
only the body sees is inferred. A `state` or `persist` is inferred from its
first value when that value says everything — `0`, `"x"`, `.calm`,
`Todo(…)`, `[1, 2]`, `{ name: "", age: 0 }`. An empty list, an empty map,
`null`, or JSON that could be anything says nothing of what will be kept
there, so the declaration says it: `state items: [Todo] = []`,
`state picked: User? = null`, `persist prefs: [String: Bool] = {}`.

**Fix:** Write the type after the name. The editor's quick fix and `wf fix
--code T25` write the type the body later assigns — `items =
items.concat([Todo(…)])` gives `[Todo]` — when the body assigns one.
