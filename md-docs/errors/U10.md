# U10 — An `else` no value reaches

```wf expect=U10
enum Tone { calm, loud }
page P(path: "/", title: "T", description: "D") {
    state tone: Tone = .calm
    Heading("Tone").h1
    match tone {
        .calm { Text("Calm") }
        .loud { Text("Loud") }
        else { Text("?") }
    }
}
```

```text
warning[U10]: every case of `Tone` has its own arm, so this `match`'s `else` is never reached
 --> src/App.wf:5:5
  |
5 |     match tone {
  |     ^^^^^
  = help: Remove the `else`
  = docs: https://webfluent.monzeromer.dev/errors/U10
```

**Fix:** Remove the `else`.
