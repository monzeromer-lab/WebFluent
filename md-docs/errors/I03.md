# I03 — A message one locale has and another does not

Warning. `nav.blog` in `en.json` and not in `ar.json`: a reader in Arabic
sees the English message, since a key the reader's locale lacks falls back to
the default locale's. Where the default locale is the one that lacks it, the
reader sees the key itself. A locale with no file at all reads every message
from the default locale's.

Under `i18n.literals`, the default locale's words are their own keys, so its
table lacking one is no fault and is not reported. **Fix:** translate it, or
remove it from the others.
