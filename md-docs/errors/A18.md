# A18 — A popover with no name

Warning.

```wf expect=A18
page P(path: "/", title: "T", description: "D") {
    state open = false
    Heading("Branches").h1
    Button("main", ref: branch) { on click { open = !open } }
    Popover(visible: open, anchor: branch) { Button("feature/layers") }
}
```

```text
warning[A18]: Popover has no accessible name
 --> src/App.wf:5:5
  |
5 |     Popover(visible: open, anchor: branch) { Button("feature/layers") }
  |     ^^^^^^^
  = help: Say what it is: Popover(visible: open, anchor: button, label: "Branches")
  = docs: https://webfluent.monzeromer.dev/errors/A18
```

```wf fixed
page P(path: "/", title: "T", description: "D") {
    state open = false
    Heading("Branches").h1
    Button("main", ref: branch) { on click { open = !open } }
    Popover(visible: open, anchor: branch, label: "Branches") { Button("feature/layers") }
}
```

**Fix:** `label: "Branches"` — what a screen reader says as the focus goes into it. A popover that is something other than a dialog says so with `role:` (`"listbox"`, `"tooltip"`), and is named as that role asks.
