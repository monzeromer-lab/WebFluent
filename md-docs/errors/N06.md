# N06 — A `fake` that does not match its group's contract

Error.

```wf expect=N06
type User { id: String, name: String }

api Backend(base: "/api") { }

api Backend.users {
    get list(page: Number = 1) at "users" -> [User]!
}

fake OneUser for Backend.users {
    lists(page) {
        .ok([User(id: "1", name: "Ada")])
    }
}

page P(path: "/", title: "T", description: "D") {
    resource users = Backend.users.list()
    Heading("Users").h1
    match users {
        .loaded(list) { Text("{list.length} users") }
        else { Spinner }
    }
}
```

```text
error[N06]: `Backend.users` has no endpoint `lists` for `fake OneUser` to answer
  --> src/App.wf:10:5
   |
10 |     lists(page) {
   |     ^^^^^
   = help: Did you mean `list`? It has `list`
   = docs: https://webfluent.monzeromer.dev/errors/N06
```

```wf fixed
type User { id: String, name: String }

api Backend(base: "/api") { }

api Backend.users {
    get list(page: Number = 1) at "users" -> [User]!
}

fake OneUser for Backend.users {
    list(page) {
        .ok([User(id: "1", name: "Ada")])
    }
}

page P(path: "/", title: "T", description: "D") {
    resource users = Backend.users.list()
    Heading("Users").h1
    match users {
        .loaded(list) { Text("{list.length} users") }
        else { Spinner }
    }
}
```

A `fake` answers a group's endpoints in place of the network, for a test
that names it in `fakes:` or for `wf verify --fakes`. It is held to what
the network would have to do: every endpoint it answers is one the group
has, every name it binds is one of that endpoint's parameters, and every
answer is the result the endpoint declares — `.ok(value)` of its type, or
`.err(error)` of its error. A fake that answered something else would let
a test pass against a server that cannot exist.

A test is held to its fakes too: each name in `fakes:` is a fake the
project or the test's file declares, no two of them answer one endpoint,
and `expect called` names an endpoint an `api` declares.

**Fix:** Answer the endpoints the group declares, by their names and
parameters, with the result each declares.
