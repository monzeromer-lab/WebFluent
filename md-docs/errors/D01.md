# D01 — A file the project does not have

Warning. In a project whose `public/` has no `img/hero.png` (the example
is not compiled here: what it draws depends on the project's files):

```wf no-check
page P(path: "/", title: "T", description: "D") {
    Heading("Team").h1
    Image(src: "/img/hero.png", alt: "The team at the launch")
}
```

The same goes for a `Video`'s `poster:` and `captions:`, an `Audio`'s
`transcript:`, and a worker's `spawn("/workers/css.js")`: the page asks
for the file and gets a 404. **Fix:** put the file in `public/`, or correct
the path.
