# N12 — An error enum that is not shaped as one

Error.

```wf expect=N12

enum SaveError {
    conflict(problem: Problem2) on 409
}

    Heading("Save").h1
```

```wf fixed
type Problem2 { title: String }

enum SaveError {
    conflict(problem: Problem2) on 409
    http(error: HttpError)
}

page P(path: "/", title: "T", description: "D") {
    state last: SaveError? = null
    Heading("Save").h1
    Text("{last == null}")
}
```

An error enum is what an endpoint declared `-> T ! E` fails with. Each
status the service answers with is a case of its own, `on` its status,
carrying the body that status sends; and one case, `http(error:
HttpError)`, takes everything else — no network, a timeout, a status no
case names. An enum that names a status is an error enum, and is held to
that shape:

- exactly one `http(error: HttpError)` case, which names no status;
- every other case names its status and carries one value;
- no status named twice.

An endpoint may also be declared `-> T!`, when the service declares no
statuses of its own: it fails with an `HttpError`.

**Fix:** Add the `http(error: HttpError)` case, give each other case one
value and its status, and keep each status to one case.
