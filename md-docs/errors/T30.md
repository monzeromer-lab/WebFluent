# T30 — A part of the browser the language does not type

Error.

```wf expect=T30
page P(path: "/", title: "T", description: "D") {
    state copied = false
    Heading("Share").h1
    Button("Copy the link") {
        on click {
            navigator.clipbaord.writeText(location.href)
            copied = true
        }
    }
    if copied { Text("Copied") }
}
```

```wf fixed
page P(path: "/", title: "T", description: "D") {
    state copied = false
    Heading("Share").h1
    Button("Copy the link") {
        on click {
            navigator.clipboard.writeText(location.href)
            copied = true
        }
    }
    if copied { Text("Copied") }
}
```

The browser's names keep the meaning the browser gives them, and the
language types them: `window`, `document`, `localStorage`, `JSON`, `Math`,
`navigator`, `location`, the timers, the element a `ref:` names, and the
event a handler is given — `on keydown(e)` is a `KeyboardEvent`, so
`e.key` is a `String` and `e.kye` is found where it is written. The table
covers what pages reach for. Anything it does not list is `T30`, whether it
is misspelt or simply a part of the browser the language leaves out.

**Fix:** When it is a slip, the help names the member meant, and the
editor's quick fix writes it. When it is a part of the browser the table
does not cover — `navigator.bluetooth`, `crypto.subtle` — reach it from a
plain script under `src/`, with JSDoc for what it takes and returns; the
call from the page is then checked like any other (see *Your own
JavaScript*).

```js
// src/share.js
/**
 * Ask the system to share a link.
 * @param {string} url
 * @returns {Promise<void>}
 */
async function share(url) {
  await navigator.share({ url });
}
```
