# T32 — A parameter written with no type

Error.

```wf expect=T32
store Todos {
    state titles: [String] = []
    action add(title) { titles = titles.concat([title]) }
}

page P(path: "/", title: "Todos", description: "D") {
    use Todos
    Heading("Todos").h1
    Button("Add") { on click { Todos.add("Milk") } }
    for title in Todos.titles { Text(title) }
}
```

```text
error[T32]: `title` of `add` says nothing of its type
 --> src/App.wf:3:5
  |
3 |     action add(title) { titles = titles.concat([title]) }
  |     ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
  = help: Every call passes a `String`: write `title: String`
  = docs: https://webfluent.monzeromer.dev/errors/T32
```

```wf fixed
store Todos {
    state titles: [String] = []
    action add(title: String) { titles = titles.concat([title]) }
}

page P(path: "/", title: "Todos", description: "D") {
    use Todos
    Heading("Todos").h1
    Button("Add") { on click { Todos.add("Milk") } }
    for title in Todos.titles { Text(title) }
}
```

A parameter is what a caller sees, so it says its type: an action's
(`action add(title: String)`), an event's (`event pick(id: String)`), a
slot's (`slot row(item: Todo)`). A lambda's parameters are worked out from
what it is passed to — `rows.filter(r => r.live)` — and are written only
when nothing says them: `derived byName = (a: User, b: User) =>
a.name.localeCompare(b.name)`.

**Fix:** Write the type. For an action's parameter, the editor's quick fix
and `wf fix --code T32` write the type every call of it passes, when they
all pass one.
