# T04 — A value that may be null, read as if it were not

```wf expect=T04
type Member { name: String, email: String? }
page P(path: "/", title: "T", description: "D") {
    state user = Member(name: "Ada", email: null)
    Heading("Profile").h1
    Text("{user.email.length} characters")
}
```

```text
error[T04]: `user.email` may be null, so `.length` may fail
 --> src/App.wf:5:12
  |
5 |     Text("{user.email.length} characters")
  |            ^^^^^^^^^^
  = help: Unwrap it first: `if let x = value { … }`, `value ?? fallback`, `value?.field`, or a check for `!= null`
  = docs: https://webfluent.monzeromer.dev/errors/T04
```

```wf fixed
type Member { name: String, email: String? }
page P(path: "/", title: "T", description: "D") {
    state user = Member(name: "Ada", email: null)
    Heading("Profile").h1
    Text("{user.email?.length ?? 0} characters")
}
```

**Fix:** Unwrap it: `if let e = user.email { e.length }`, `user.email?.length ?? 0`, or `(user.email ?? "").length`. Your editor's quick fix, and `wf fix --code T04`, write the `?.` for you.
