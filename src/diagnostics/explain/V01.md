# V01 — A bare word that means nothing

```wf expect=T13
page P(path: "/", title: "T", description: "D") {
    Heading("Save").h1
    Button(primary)
}
```

```text
error[T13]: nothing declares `primary`
 --> src/App.wf:3:12
  |
3 |     Button(primary)
  |            ^^^^^^^
  = help: Did you mean `.primary`? Declare it — a `state`, a `const`, an `action`, a prop — or check the spelling. In the browser it would be a ReferenceError
  = docs: https://webfluent.monzeromer.dev/errors/T13
```

```wf fixed
page P(path: "/", title: "T", description: "D") {
    Heading("Save").h1
    Button("Save").primary
}
```

**Fix:** Write the flag with its dot — `Button("Save").primary` — or declare the name. The word is also a name nothing declares, so the build stops on it as `T13`, and the two are one mistake: the `T13` is reported, carrying what `V01` suggests (Did you mean `.primary`?) and its fix. `V01` names the check that reads a bare word as a flag written without its dot.

A name a branch binds is declared through the whole of its block, however
deep the element that reads it: `if let why = e.reason { Row { Pill(why) } }`,
and a case's payload, `.failed(why) { … }`, draw nothing.
