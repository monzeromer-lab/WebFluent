# R02 — A route parameter with no page parameter

```wf expect=R02
page Profile(path: "/u/:id", title: "T", description: "D") {
    Heading("Profile").h1
}
```

```text
error[R02]: the route `/u/:id` names `:id`, and the page declares no parameter `id`
 --> src/App.wf:1:1
  |
1 | page Profile(path: "/u/:id", title: "T", description: "D") {
  | ^^^^
  = help: Declare it: `page Profile(path: "/u/:id", id: String)`, then read `id`
  = docs: https://webfluent.monzeromer.dev/errors/R02
```

```wf fixed
page Profile(path: "/u/:id", title: "T", description: "D", id: String) {
    Heading("Profile {id}").h1
}
```

**Fix:** Declare the parameter the route names — `page Profile(path:
"/u/:id", id: String)` — and read it by name. A declared parameter the route
has no `:name` for is not an error: it is the page's data, which makes the
page a template — `wf render`, the `Template` API and a test's `data:` hand
it its data, and `wf build` leaves the page out (no route, no file, no page
of a PDF).
