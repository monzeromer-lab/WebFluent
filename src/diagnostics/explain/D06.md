# D06 — A script loaded on consent, with nothing to ask for it

Warning. A `meta.scripts` entry is marked `"load": "consent"`, so it loads
only once the reader accepts in a `ConsentBanner` — and the program has no
`ConsentBanner`, so nobody is asked and the script never loads.
**Fix:** place a `ConsentBanner("…")` in `app`, where every page shows it,
or drop `"load": "consent"` if the script needs no consent.
