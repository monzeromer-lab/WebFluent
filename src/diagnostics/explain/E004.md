# E004 — A file in the WebFluent 2 grammar

```wf expect=E004
Page Home (path: "/") {
    Text("Hi")
}
```

```text
error[E004]: `Page` is a WebFluent 2 declaration, which this WebFluent no longer reads
 --> src/App.wf:1:1
  |
1 | Page Home (path: "/") {
  | ^^^^
  = help: WebFluent 8 no longer reads the WebFluent 2 grammar: migrate the project with a 7.x release first (`cargo install webfluent --version ^7`, then `wf migrate`), then run this `wf migrate` for the rest
  = docs: https://webfluent.monzeromer.dev/errors/E004
```

```wf fixed
page Home(path: "/", title: "T", description: "D") {
    Heading("Hi").h1
}
```

**Fix:** WebFluent 8 no longer migrates the WebFluent 2 grammar. Install a
7.x release (`cargo install webfluent --version ^7`), run its `wf migrate`
over the project once — it rewrites it in place — then run this release's
`wf migrate` for what changed since.
