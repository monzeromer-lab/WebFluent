# About

**Field Notes** is a notebook kept in public: a few lines about whatever the garden, the kitchen or the road taught me that week.

## Why write it down

Memory is a poor gardener. I wanted one place for the sowing dates, the recipes that worked, and the lessons I keep having to learn twice — and it turns out that writing a note for somebody else makes it a better note.

## How the site is built

The whole site is static. Every note is a record in one JSON file, read when the site is built, and every page is written out as plain HTML.

- There is no server and no database.
- There are no accounts. The notes you save are kept in your own browser.
- The site follows your system's light or dark setting; the moon in the corner overrides it.

It is written in [WebFluent](https://github.com/monzeromer-lab/WebFluent).

> Thank you for reading. If a note helped, the best thanks is a seed swap.
