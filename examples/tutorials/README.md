# Tutorials

The finished projects of the guide's [Tutorials chapter](../../md-docs/35-tutorials.md),
each built there step by step. None needs a server.

| Level | Project | What it is |
|---|---|---|
| Easy | [`easy-todos`](easy-todos) | A todo list kept in the browser: a store, a component, a keyed list, tests that click |
| Medium | [`medium-field-notes`](medium-field-notes) | A notebook site built statically: data files, a page per note, Markdown, search and tags |
| Hard | [`hard-pocket`](hard-pocket) | A budget tracker: Money and dates, forms, a migration, two languages, a script of its own, offline |

In any of them: `wf serve` to run it, `wf test` for its tests, `wf build`
for a site any static host serves.
