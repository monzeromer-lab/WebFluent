State and reactivity

This is the chapter most readers find hardest, so it goes slowly. A value you declare with state is read by whatever shows it — and only what reads it draws again when it changes.

What redraws

Nothing re-runs the whole page. The compiler sees that Text("Clicked {count} times") reads count, and ties that one text node to it. Click +1 above: only that line changes.
