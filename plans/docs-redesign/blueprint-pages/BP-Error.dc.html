ErrorT05Types

A field or method that does not exist

You read a field the record’s type does not declare. In the browser it would quietly be undefined, so the compiler stops here instead.

What the compiler said

error[T05]: `User` has no field `nmae`
 --> src/pages/Profile.wf:3:18
  |
3 |     Heading(user.nmae).h1
  |                  ^^^^
  = help: Its fields are `id`, `name`
  = docs: webfluent.dev/errors/T05

The fix

type User { id: String, name: String }

page Profile(path: "/me", title: "Me") {
    state user = User(id: "1", name: "Ada Lovelace")
    Heading(user.name).h1
}

Ada Lovelace

Why this rule exists

A typo in a field name is the most common bug a type checker can catch before a reader sees it. The nearest name is offered as a fix, and your editor applies it.
