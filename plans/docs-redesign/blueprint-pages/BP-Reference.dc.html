Button

A control that does something when pressed. What it shows goes in its block; what it does goes in on click.

Examples

Submit a form

Inside a Form, type: .submit sends it; every other button never does.

Form {
    Input(bind: email, label: "Email")
    Button("Join", type: .submit).primary
}

While it saves

An async action is pending while it runs; read it to disable the button.

Button("Save", disabled: save.pending)
    .primary { on click { save() } }

A choice of two

A ButtonGroup joins buttons that belong together.

ButtonGroup {
    Button("Day")
    Button("Night").primary
}

Events

Every DOM event, on its <button>: on click, on focus, on key("mod+s"). A handler written on a component call reaches its root, so a styled button of your own is clickable too.

Accessibility

It renders a real <button type="button">, so Tab, Enter and Space work with no extra code.

A button needs text a reader can see or hear; one with neither is A05.

An aria-label must contain the visible words, or voice control cannot find it: A15.
