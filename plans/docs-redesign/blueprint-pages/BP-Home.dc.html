What are you making?

Pick one and the guide, the recipes and the reference filter to what applies. The switch in the header changes it anywhere.

A website

wf init -t static

A web app

Routes, stores, live data

wf init -t spa

A PDF

Reports, invoices, CVs — no browser needed

wf init -t pdf
