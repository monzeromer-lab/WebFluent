Button

عنصر تحكّم يفعل شيئًا حين يُضغط. ما يعرضه يذهب في كتلته، وما يفعله يذهب في on click.

منذ 3.0الويبالتطبيقليس في PDF ولا الشرائحاعرض المصدر
النغمة
الحجم
{{heightLabel}}
{{padLabel}}
radius {{radiusLabel}}
{{snippet}}

أمثلة

أرسل نموذجًا

داخل Form، يرسله type: .submit؛ وأي زر آخر لا يرسله أبدًا.

Form {
    Input(bind: email, label: "البريد")
    Button("انضم", type: .submit).primary
}

أثناء الحفظ

الإجراء غير المتزامن معلّق ما دام يعمل؛ اقرأه لتعطيل الزر.

Button("احفظ", disabled: save.pending)
    .primary { on click { save() } }

خياران

يجمع ButtonGroup أزرارًا تنتمي معًا.

ButtonGroup {
    Button("نهار")
    Button("ليل").primary
}

الخصائص

الخاصيةالنوعالافتراضيماذا تفعل
labelStringمطلوبةما يقوله الزر. موضعية.
toneالنغمة.primaryواحدة من ستّ نغمات، أولها .primary
sizeالحجم.mdارتفاعه 36 أو 44 أو 52 بكسل، من .sm إلى .lg
outlinedBoolfalseحدّ بلا تعبئة
pillBoolfalseطرفان مستديران بالكامل
fullBoolfalseيملأ عرض صفّه
typeButtonType.button.submit يرسل النموذج الذي هو فيه
disabledBoolfalseيُبهته ويتجاهل النقرات

الأحداث

كل حدث DOM، على عنصر <button> نفسه: on click وon focus وon key("mod+s"). المعالج المكتوب على استدعاء مكوّن يصل إلى جذره، فيُنقر زرّك المنسّق أيضًا.

إتاحة الوصول

يُرسم <button type="button"> حقيقيًا، فتعمل Tab وEnter وSpace بلا شيفرة إضافية.

يحتاج الزر نصًا يراه القارئ أو يسمعه؛ والزر الخالي منهما هو A05.

يجب أن يحتوي aria-label على الكلمات الظاهرة، وإلا لم يجده التحكّم الصوتي: A15.
