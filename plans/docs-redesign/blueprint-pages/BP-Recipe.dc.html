How to fetch and show a list

Ask a server for a list, show a placeholder while it comes, and draw each item. Done in 14 lines.

type User { id: String, name: String }

page Team(path: "/team", title: "Team") {
    resource users: [User] = fetch("/api/users", on: .focus)

    match users {
        loading { Skeleton(height: "20px") }
        error(e) { Alert(e.message).danger }   // a first load that failed
        ready(list) {
            for u in list by u.id {             // keyed: rows keep their state
                Text(u.name)
            }
        }
    }
}

const users = WF.resource("/api/users", { on: "focus" });
WF.match(root, () => users.state, null, {
  loading: () => WF.el("div", { class: "wf-skeleton" }),
  ready: (list) => WF.each(root, list, row, { key: (u) => u.id }),
});

What's happening

resource starts the request when the page draws and asks again when the tab regains focus. match draws one arm for its state: the skeleton while loading, the list when ready.

A refresh keeps the list on screen and redraws in place, so a row keeps its focus. A refresh that fails keeps the old data and sets users.error.
